# SPM-mouse-gait
A Python pipeline to process c3d files from 3D marker-based motion capture data performed on mice and to determine the reproductibility and repeatability 
## Features

Loads C3D files from multiple acquisition dates and mice

Extracts and preprocesses marker trajectories

Detects stance phases

Computes joint kinematics and trotting speed

Normalizes gait cycles to 101 points

Saves processed joint angles and speed data

Compute reproducibility metrics

Performed SPM analysis
